# PID 训练场 · 一阶倒立摆

Robocon 2027 备赛用的一阶倒立摆 PID 调参训练器（静态网页，零后端）。

## 特性

- 一阶倒立摆物理仿真（θ'' = (g/L)·sinθ + u/(mL²) − (b/mL²)·θ'，2ms 半隐式欧拉积分）
- 摆球质量 m 每次重置随机生成（0.6~1.8 kg）
- 控制器只能看到带高斯噪声的观测（σ 可调），看不到真值
- 实时曲线：观测 vs 真值 vs 目标角度（最近 5 秒 @50Hz）
- 可设定初始偏离角度（-180°~180°）和目标角度
- 拖动摆杆末端创建扰动（松手后恢复动力学）
- PID 输出限幅 + 抗积分饱和
- 预设参数：全 0 / 仅 P / P+D / PID 完整

## 使用

直接打开 https://fjienan.github.io/pid-trainer/ ，或下载 index.html 本地打开（无外部依赖，仅 Chart.js CDN，断网时图表不加载但仿真仍可运行）。

### URL 参数

- `?autorun=1`：页面加载后自动开始仿真

## 参考

- 物理模型参数：L=0.5m 默认（0.3~0.8 可调），阻尼 b=0.06
- 控制周期 50Hz，物理步长 2ms

## 测试

node /tmp/pid_sim_test.js 的结论（随机质量 100 次仿真，15s 后 ‖θ‖<5° 算稳定）：

| 参数组 | 成功率 |
|---|---|
| Kp=10 Ki=2 Kd=3（默认） | 100/100 |
| Kp=12 Kd=3（P+D） | 100/100 |
| Kp=12（仅 P） | 7/100 |
| 全 0 | 0/100（必倒） |

> 仅 P 拿不下带噪声的系统（D 项被噪声放大是教学点）；150° 大角度需要更强参数（Kp=14 Ki=8 Kd=4 uMax=20）。
